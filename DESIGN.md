# Roots dashboard design

Visual authority: Roots dashboard variant in the user-supplied shared chat, inspected in the browser on October 24, 2026. This extends that established surface and its tasks.

Warm off-white page, white panels, pale sage selected controls and feature surfaces, deep forest primary actions. A single readable sans family; compact heading scale and tabular figures. Horizontal section navigation preserves the reference. Thin sage-gray borders; 14px panel radii. Line icons share one stroke width. Color communicates selected state, opportunity category, or conditions.

Layout: brand and workspace controls, navigation, page heading, compact metrics, opportunity and next-step columns, then active project and community activity. Secondary views reuse spacing and controls. Funding detail is a side panel; ordinary editing is inline. Responsive navigation remains visible and scrollable; panels become one column. No decorative animation; state changes under 200ms and reduced-motion support.

Surface mode: Operate. Primary task: identify viable support, see unresolved conditions, draft a project and match a team. All fixture metrics carry a demo label. Real program links are separate from fictional activity.
