# Roots

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Guild organizers connect opportunities to community projects and volunteers. Participants explore benefits with clear conditions. These roles come from the supplied shared conversation.

## Product Purpose
Two usable UI concepts: an opportunity/project workspace and a community dashboard. Trail is excluded.

## Capabilities and Constraints
This deliverable is a browser-local UI prototype. People, metrics and the project are illustrative. Program terms are the supplied October 24, 2026 research snapshot, not newly verified live eligibility. No messages, applications or payments are submitted. Keep potential, approved and received funding distinct. Ordinary Guild hours never automatically count toward outside benefit programs.

## Brand Commitments
Roots for East Bay Permaculture Guild. The user requested ChatGPT-like UI typography, no top metric-card grid, and confirmed subtle green accents. Preserve source concepts while simplifying their presentation.

## Evidence on Hand
Shared conversation: https://chatgpt.com/share/6add3d4f-2930-83e9-8179-e55f27ba6661. Existing screens were inspected in the browser, including all eight non-Trail sections.

## Implementation Assumptions
Buildless HTML, CSS and JavaScript makes the portable UI easy to inspect. Local storage retains demonstration edits. No backend integration was requested.
